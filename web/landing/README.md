# PROTO-PHØR0S landing

Fictional DefTech logistics platform (portfolio project). Single Design Component.

- Open index.html in a browser (support.js must stay beside it).
- Images live in uploads/.
- Palette: bg #08090a, panel #0d0f10, line #1c1f21, text #e6e7e3, muted #8b8f8c, OK #6fdc8c, warn #d9a441, alert #e0574a.
- Fonts: Archivo (text), IBM Plex Mono (labels/data), custom pixel logo drawn from a 6x7 glyph grid in the logic class.
- Sections: hero, ticker, mission, modules, analytics (charts), ledger tabs, access by unit, contact, Echo copilot widget (simulated replies), demo modal.
- Green night-vision filter only on the jet image.
